# Security policy

## Supported versions

Only the [latest release](https://github.com/william1010121/Botling/releases/latest)
gets security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/william1010121/Botling/security/advisories/new)
with what you found, how to reproduce it and the version you tested.

In scope, for example: a way for a bot, a plugin or a page shown in the chat to run commands,
read files or use secrets without the approval the app is meant to ask for, or a way around the
install card for external plugins.
